The goal model

A Dixon–Coles model fitted by weighted maximum likelihood. Each side gets a goal rate:

log λhome = base + attack[home] − defence[away] + home_adv
               + b_rest · rest(home) + b_cong · congestion(home)

Those two rates give a probability for every scoreline, and every number on the Predict tab — win chances, over/under, both teams to score, expected goals — is read off that one distribution. That is why the grid and the goals panel can never disagree.

Four things that matter

  • Low-score dependence (ρ). Independent Poisson under-predicts 0–0 and 1–1 and over-predicts 1–0. The Dixon–Coles correction fixes it.
  • Time decay. Older matches are weighted down on a half-life, so recent form leads without discarding history.
  • Ridge shrinkage. Attack and defence are pulled toward the league mean, which stops a club with few matches getting an extreme rating.
  • Schedule effects are fitted, not assumed. Rest days and 14-day congestion are computable for every historical match, so they are estimated from data rather than guessed.

Shots and possession

The same additive shape, fitted by weighted ridge regression on real box scores:

possession = c + pull[team] − pull[opponent] + home
log(shots)  = c + generation[team] − suppression[opponent] + home

The design is antisymmetric in team and opponent, which is what makes possession sum to 100 and keeps the two halves of a fixture consistent with each other.

    Judging it honestly

    A 55% favourite loses 45% of the time, so single results prove nothing. The command-line tool ships a walk-forward backtest that refits on matches strictly before each kickoff and scores the prediction it would have made — log loss, ranked probability score, and a calibration table against a base-rate baseline. That, not any one call, is the thing to judge.

    Run python -m spl.cli backtest on your own snapshot.
